## Project Overview

This is an educational Unity project that was developed and maintained throughout the semester.  
The project is currently undergoing a refactoring phase aimed at removing unnecessary features and simplifying the overall logic.  
Once the cleanup is complete, new development goals will be defined and implemented gradually.

## Planned Features

- Performance optimization  
- Reduction of application size  
- A smooth and user-friendly UI  
- A toolkit for playing tabletop role-playing games  
  *(This feature will be implemented at the final stage, after the project has been fully cleaned up.)*
